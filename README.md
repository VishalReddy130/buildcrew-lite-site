# BuildCrew Lite — public product site

This repository hosts the public-facing BuildCrew Lite early-beta website and its free sample download.

## What is included
- Static product landing page and interactive preview
- Screenshot of the local dashboard
- Free sample ZIP
- GitHub Pages deployment workflow

## Product scope
BuildCrew Lite is a local-first workflow kit for AI-assisted development. It provides role briefs, dependency-aware task planning, Markdown handoffs, a local dashboard and human review records. It does **not** autonomously run AI agents, include model/API credits, edit code automatically, or provide cloud collaboration.

## Local preview
Open `index.html` in a browser. The site is static and requires no build step.

## Publishing
GitHub Actions deploys the site to GitHub Pages when changes are pushed to `main`.
