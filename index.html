WHAT IT IS — AND ISN'T

A useful tool, without the grand claims.

BuildCrew is deliberately small. It brings structure to AI-assisted work without pretending to be an autonomous engineering team.

Included

  • Role-specific instruction briefs
  • Local project plan and dashboard
  • Dependency-aware task selection
  • Markdown handoff generation
  • Human review and evidence records
  • Python standard-library helper

Not included

  • No autonomous agent runtime
  • No model or API access
  • No cloud hosting requirement
  • No third-party Python packages
  • No automatic code execution
  • No replacement for code review
