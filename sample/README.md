# BuildCrew Lite — free sample

This folder is a small, free preview of the BuildCrew workflow. It is not the complete paid package.

## Files
- `sample_project_plan.json`: a fictional six-task inventory API example.
- `EXAMPLE_HANDOFF.md`: the Markdown instruction generated for one sample task.

## What the sample demonstrates
BuildCrew represents work as tasks with owners, priorities, dependencies, statuses and acceptance criteria. It can select dependency-ready work and generate a focused handoff for a coding assistant.

## Important limits
The demo is not an autonomous agent runtime. It does not execute code, call an LLM, include API credits, or verify that AI-written code is correct. Human review remains necessary.
